## Guardrails

- Never close `ProviderQueue.queue` — the code comment at core/bifrost.go:137-165 explains why (TOCTOU panic risk); `pq.done` is the only shutdown signal.
- Never let a request bypass the `handoff` CAS when adding a new terminal-delivery path — both `claimDelivery` and `abandonDelivery` must remain mutually exclusive.
- Do not rotate keys on 5xx/529 — this is a deliberate, tested rule (F-001-TC9), not an oversight.
- Stop and ask if a change would require closing `pq.queue`, removing the `handoff` atomic, or altering `MaxRetries` semantics — these are structural invariants, not implementation details.
